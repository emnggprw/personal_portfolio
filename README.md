# Personal Portfolio

A personal portfolio built using Flutter to showcase my projects, skills, and ongoing work.

## Getting Started

This project serves as a central hub for all the applications and projects I have developed or am currently working on. It provides an interactive and visually appealing way to present my work.

## Features

- Overview of completed and ongoing projects
- Interactive UI built with Flutter
- Smooth navigation and responsive design

## Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/emnggprw/personal_portfolio.git
   ```
2. Navigate to the project directory:
   ```sh
   cd personal_portfolio
   ```
3. Install dependencies:
   ```sh
   flutter pub get
   ```
4. Run the project:
   ```sh
   flutter run
   ```

## Technologies Used

- **Flutter** – Frontend framework
- **Dart** – Programming language
